# Instructions for coding agents

This repository is the Recipe Catalog: scaffolds and recipes as Markdown files (`FORMAT.md`).

- To harvest a recipe from someone's project, follow `skills/harvest-recipe/SKILL.md`.
- To carry out a recipe's instructions in a project, follow `skills/apply-recipe/SKILL.md`.
- Change items under `stacks/` only through a new version with a changelog entry, and run `npm run catalog -- lint` before you finish.
- Never write a real key, token, account id or a project's own package name into an item; use a parameter.
